# Agent 工具权限与文件保护

更新日期：2026-10-19。对应产品评审 P0-01 与 P0-02 的第一批实现。

## 已实现

- 主进程按已保存的会话绑定读取 Agent，生成每次运行独立的权限快照；新对话先保存绑定再发起聊天。未保存的会话和已删除的 Agent 不会降级成通用工具权限。
- 工具名称白名单与联网、写入、删除开关共同约束执行。白名单为空表示不限制名称，仍遵守分类开关；非空表示只允许列出的工具。
- 模型获得的工具 schema、系统提示中的工具列表按有效权限过滤。执行器再次检查权限，模型返回未获准调用也不会执行。预调用工具同样受限。
- 补齐所有内置工具的风险策略；未知策略默认拒绝。打开网页也归入联网操作，生成 PDF/PPTX 归入写入操作。
- Agent 要求高风险确认时，写入、删除和系统操作必须确认。全局工具要求确认时，Agent 不能将其放宽；没有确认入口时拒绝执行。
- Agent 编辑窗口可设置分类开关、工具白名单和高风险确认。
- 从对话创建的任务保存 agentProfileId，并在执行、恢复或重跑的新一轮运行中读取对应权限。无 Agent 的独立任务和旧任务使用应用默认权限。
- 通用助手默认开放工具分类，并开启高风险确认；自定义 Agent 原有的关闭设置开始实际生效。若旧 Agent 无法联网或写入，可在编辑窗口明确开启所需权限。

权限在一次运行开始时快照，编辑配置不会撤回已经开始的操作。如需立即停止，先取消当前运行，再修改权限并重新执行。

## 明确的边界

“允许联网工具”只控制工具调用，不控制在线对话模型、在线生图或知识库模型请求。强制本地模式、密钥保护、日志脱敏和结构化成果验收仍是后续 P0 工作。

应用自己的会话/任务持久化不受 Agent 的文件写入开关影响；该开关控制模型调用的业务工具。单次高风险确认仍走现有确认队列，取消和超时机制保持适用。

## 回归验证

`npm run test:system` 增加真实执行器与聊天/任务调用链的测试，覆盖工具策略完整性、未保存会话、Agent 删除、分类限制、白名单交集、未知工具、并发隔离、权限快照、确认拒绝，以及模型强行返回禁用工具。外部工具 I/O 与模型返回受控模拟，不代表真实模型质量或桌面 UI 交互验收。

另运行类型检查、模型配置回归、行为 eval 和生产构建。

## 第二批：工作区授权与文件变更保护

设置 → 工具权限增加“工作区授权”和“文件恢复”：

- 默认只开放应用的成果目录。用户通过系统目录选择器添加其他工作区，新授权默认只读；写入和移入回收站可分别开启，且仍与 Agent 自身权限取交集。
- 撤销授权立即影响尚未执行的文件操作。确认结束、取得文件操作队列后会重新检查权限、路径与内容；授权记录损坏时停止文件访问，不自动回退到可能包含已撤销授权的旧备份。
- 检查路径规范化、真实路径、目录边界与链接。拒绝符号链接、目录联接、可疑 Windows 设备名称和备用数据流；有多个硬链接的文件不能修改。应用配置、日志、密钥和文件恢复备份不向 Agent 文件工具开放。
- 模型参数先校验并复制，确认卡片展示规范化后的源/目标路径；小文本修改展示修改前后预览，长内容明确截断。确认参数副本的变化不会更改实际调用。现有文件变更始终确认，即使普通工具策略配置为自动执行。
- 修改、移动、删除已有普通文件前保存完整备份与 SHA-256 校验；备份失败则不执行操作。恢复会再备份当前版本，并要求当前工作区仍有写入授权以及主进程原生确认。
- 目录复制、移动、解压不再删除已有目标目录；必须提供新目标。阻止源目标相同、互相包含和移动工作区根目录。目录移动可反向移回，未实现目录级批量事务恢复。
- ZIP 改用显式依赖 JSZip，在进程内检查成员路径、特殊条目和展开大小，解压到临时目录后发布。拒绝路径穿越、链接、重复目标及过量展开，不再执行 PowerShell 压缩/解压脚本。
- 应用内文件工具串行执行；等待队列时取消的调用不会稍后写入。模型调用与网络工具不占用此队列。

限制：文件操作涉及的现有内容合计最多 50 MiB、2000 个条目；ZIP 输入与展开内容分别不超过 50 MiB。备份总量最多 512 MiB，界面展示最近 100 条。达到备份容量后停止需要备份的修改，保留已有备份，不自动淘汰。

恢复记录保存在 `userData/ai-agent/file-revisions/`，授权记录为 `userData/ai-agent/workspaces.json`。不自动为历史 Agent 授予用户目录权限；升级后第一次访问原有工作目录需要在设置中授权。RAG 文档选择与索引管线不受该文件工具工作区列表控制。

这些是应用层保护，不是操作系统沙箱：其他进程恶意并发替换路径的所有竞态尚未消除；已完成的文件操作不会因取消自动撤销。普通文件写入失败可使用备份恢复，目录复制中途失败可能留下新建的部分目录，不承诺整批事务回滚。

`scripts/test-file-safety.mjs` 使用临时真实文件和真实执行器，覆盖只读授权、越界、目录联接与祖先替换、硬链接、确认拒绝/取消、参数篡改、确认期间外部修改、授权撤销、备份与恢复、磁盘写入失败、破坏性目录覆盖、ZIP 攻击样本与展开大小限制。原生对话框用受控返回替代；尚未进行桌面 UI 交互验收或其他操作系统的端到端验收。
